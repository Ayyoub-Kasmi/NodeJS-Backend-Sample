# NodeJS-Backend-Sample

This repository is not our project's main repo, it's just a code sample that you can use to have some hints about what you should be doing in your code in terms of
structure, syntax, maybe packages and stuff.

Note that the app.js file is containing the link to my own MongoDB database, you can keep it as it is or better change it to your own to see the changes yourself.

Clone the repo to your local machine, run "npm install" to install the necessary packages found in package.json, and then run the server using "node app.js"
